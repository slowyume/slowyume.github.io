# PlayWithGoal — AI Shop & Rest Quest Edition

기존 PlayWithGoal의 부드러운 UI와 RPG 흐름을 유지하면서 장비 상점과 휴식 퀘스트를 추가한 버전입니다.

## 추가 기능
- 현재 플레이어 레벨을 기준으로 무기/갑옷을 랜덤 생성하는 장비 상점
- 상점의 장비를 Gold로 구매하고 즉시 장착
- `🎲 다른 장비 보기`로 새로운 랜덤 장비 목록 생성
- 휴식 퀘스트에서 200 / 250 / 300 G 보상 선택
- 입력창에 자신이 원하는 휴식을 직접 작성
- 입력창 placeholder와 예시 버튼으로 AI 스타일의 휴식 예시 제공
- 브라우저 localStorage 저장
- 실제 생성형 AI API는 사용하지 않으며, GitHub Pages에서 API 키가 노출되지 않도록 브라우저 내부 랜덤 생성 방식으로 구현

원본 구조의 플레이어 정보, 영지, 일일 퀘스트, 주간 보스, 퀘스트 관리 흐름을 유지합니다.
